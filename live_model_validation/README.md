# Live model validation

Контур для проверки сохранённой модели на свежих объявлениях Avito и CIAN.

## Полный запуск

Из `E:\CR`:

```powershell
python -m live_model_validation.run
```

Что произойдёт:

1. Твой Avito-парсер обработает первый сегмент и одну страницу выдачи.
2. Твой CIAN-парсер обработает первый сегмент и одну страницу выдачи.
3. Карточки сохранятся в новой папке `runs/<дата_время>`.
4. Данные получат те же ML- и геопризнаки, что использовались при обучении.
5. Модель рассчитает цену и сравнит её с ценой объявления.

По умолчанию обрабатываются все карточки первой страницы. Для быстрого теста:

```powershell
python -m live_model_validation.run --max-cards 5
```

При капче лучше запускать без `--headless`, пройти её вручную и нажать Enter в
терминале. Фоновый режим:

```powershell
python -m live_model_validation.run --headless --max-cards 5
```

Запуск следует выполнять из обычного PowerShell. В защищённых песочницах
Playwright может не иметь права создать браузерный процесс; такой сбой
записывается в `parser_errors.json`.

## Проверка готовых raw

```powershell
python -m live_model_validation.run `
  --skip-parse `
  --avito-raw path\to\avito_raw.csv `
  --cian-raw path\to\cian_raw.csv
```

## Результаты

В папке конкретного запуска:

- `avito_links.csv`, `cian_links.csv` — ссылки первой страницы;
- `avito_raw.csv`, `cian_raw.csv` — разобранные карточки;
- `fresh_predictions.csv` — цена сайта, прогноз, ошибка и ссылка;
- `fresh_metrics.json` — MAE и другие метрики.

Основной показатель считается отдельно для объявлений не дороже 40 млн руб.
Более дорогие объявления прогнозируются, но помечаются как выходящие за диапазон
обучения.
