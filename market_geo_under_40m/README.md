# Market + Geo, price <= 40M RUB

Отдельный обучающий контур без объектов строго дороже 40 млн руб.

## Важно

- `avito_raw.csv` и `cian_raw.csv` не изменяются.
- Записи стоимостью ровно 40 млн руб. сохраняются.
- Удаляются 102 записи строго дороже 40 млн руб.
- Используется то же исходное разбиение train/validation/test, поэтому сравнение
  с полной моделью выполняется на одинаковых оставшихся test-объектах.
- Дорогие строки исключаются и из CatBoost, и из базы рыночных аналогов.

Полная модель до фильтра сохранена в:

`E:\CR\model_report_archive\full_market_2026-06-14`

## Запуск

```powershell
python -m market_geo_under_40m.run_pipeline --seeds 42
python -m market_geo_under_40m.evaluate
```

## Этапы

- общая очистка и 45 дополнительных геопризнаков;
- фильтр `price_rub <= 40_000_000`;
- две CatBoost-модели;
- leakage-safe прогноз по локальным аналогам;
- подбор весов только на validation;
- evaluation и production-модели.

## Полученный результат

- MAE: **873 985 руб.**
- Median absolute error: **453 503 руб.**
- MAPE: **8,81%**
- R²: **0,9513**
- Улучшение относительно полной модели: **237 166 руб.**
- Дополнительный выигрыш именно от переобучения: **5 432 руб.**
